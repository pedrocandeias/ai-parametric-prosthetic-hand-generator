--------------------------------------------------------------------------------
- O AppImageLauncher instalado no sistema intercepta a execução dos AppImage e,
  em modo headless (sem sessão gráfica) com HOME redirigido, provoca segfault
  ("cannot read config file" / QIODevice appimagelauncher.cfg). Por isso os dois
  AppImage foram EXTRAÍDOS e executou-se o binário interno via ./AppRun, como o
  próprio protocolo previa ("extrai-os e executa os binários internos").
    Bambu:  <extração>/squashfs-root/AppRun          (define LC_ALL=C, LD_LIBRARY_PATH)
    Prusa:  <extração>/squashfs-root/AppRun
- Isolamento dos perfis globais do utilizador:
    HOME redirigido para um diretório de trabalho dedicado (não os perfis reais).
    PrusaSlicer: --datadir para um diretório temporário dedicado.
    Bambu Série B: processo/filamento carregados de ficheiros próprios (ver §5),
    sem escrever nos presets do utilizador.
- NOTA: o sandbox do ambiente bloqueou a escrita em /tmp; usou-se um diretório de
  trabalho isolado dentro da área autorizada, funcionalmente equivalente a /tmp
  (isolado dos perfis globais). Nenhum perfil global do utilizador foi alterado.

3. SÉRIE A (ENSAIO A) — FATIAMENTO DOS 4 PROJECTOS ARQUIVADOS (perfis embebidos)
--------------------------------------------------------------------------------
Objetivo: re-fatiar cada projecto TAL COMO FOI PREPARADO (definições, filamento e
layout de placa embebidos no próprio 3MF) para obter tempo/filamento/massa, que
NÃO estavam guardados nos ficheiros (o slice_info.config Bambu continha apenas o
cabeçalho; o projecto PrusaSlicer não continha G-code).

Bambu (×3) — comando genérico:
  HOME=<work>/bambu_home  <work>/squashfs-root/AppRun \
    --slice 0 \
    --outputdir <out>/<caso> \
    --export-3mf <caso>_sliced.3mf \
    <docs/print-validation>/<projecto>.3mf

  Projectos:
   - flexy_beast_teen_15_print.3mf
   - unlimbed_phoenix_hand_teen_15_print_project.3mf
   - unlimbed_phoenix_hand_teen_15_print_project_PETG.3mf
  Saída relevante por caso: result.json (tempo/massa), plate_1.gcode (cabeçalho
  com comprimento/camadas).

PrusaSlicer (×1) — Paraglider (Prusa MINI):
  HOME=<work>/bambu_home  <work>/prusa_extract/squashfs-root/AppRun \
    --export-gcode \
    --datadir <work>/prusa_datadir \
    --load <work>/configs/override_ascii.ini \   (binary_gcode = 0, para cabeçalho legível)
    --output <out>/paraglider_ascii.gcode \
    <docs/print-validation>/paraglider_15_teen_prusa_print_profile.3mf

4. SÉRIE B (ENSAIO B) — COMPARAÇÃO DIGITAL CONTROLADA (12 casos: 3 modelos × 4 perfis)
--------------------------------------------------------------------------------
Condição virtual COMUM idêntica nos 12 casos:
  Impressora  : Bambu Lab A1 (bico 0,4 mm)              [perfil de máquina de sistema]
  Filamento   : Bambu PLA Basic @BBL A1                 [preset de sistema, herança resolvida]
  Processo    : herda "0.20mm Standard @BBL A1" e fixa explicitamente:
                  layer_height = 0.20 mm
                  wall_loops = 2
                  sparse_infill_density = 15%
                  sparse_infill_pattern = grid
                  enable_support = 0   (POLÍTICA ÚNICA DE SUPORTES: SEM suportes)
                  brim_type = auto_brim
  Layout      : --arrange 1 --orient 0 --ensure-on-bed
                (mantém a ORIENTAÇÃO de cada peça exportada; o fatiador apenas
                 translada/coloca as peças na placa; quando não cabem numa placa,
                 gera automaticamente uma 2.ª placa A1)

Input de cada caso = conjunto de PEÇAS imprimíveis já exportadas pela plataforma:
  Flexy Beast      : flexy_beast/<perfil>/parts/*.3mf                 (12 peças)
  Paraglider Hand  : paraglider_hand/<perfil>/parts/*.3mf             (7 peças)
  UnLimbited Phoenix: unlimbed_phoenix_hand/<perfil>/*_<parte>.3mf    (8 peças)

Comando genérico (Bambu):
  HOME=<work>/bambu_home  <work>/squashfs-root/AppRun \
    --slice 0 --arrange 1 --orient 0 --ensure-on-bed \
    --load-settings "<...>/Bambu Lab A1 0.4 nozzle.json;<work>/configs/handfab_campB_process.json" \
    --load-filaments "<work>/configs/pla_basic_a1_resolved.json" \
    --outputdir <out>/campB/<modelo>_<perfil> --export-3mf sliced.3mf \
    <lista de ficheiros .3mf das peças>
